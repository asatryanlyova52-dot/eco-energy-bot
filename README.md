# EcoEnergyBot

Հայերեն Telegram բոտ էներգաարդյունավետության համար՝ նույն ոճի reply կոճակներով, արագ վիկտորինայով, սարքերի ծախսի համեմատությամբ և ԱԲ չատ-օգնականով։

## Ինչ կա ներսում

- Հայերեն գլխավոր մենյու՝ 8 կոճակով
- Էներգախնայողության մինի վիկտորինա
- Էկո խորհուրդների բաժին
- Սարքերի ծախսի համեմատության հուշում
- ԱԲ օգնական՝ էներգախնայողության թեմայով system prompt-ով
- 5 պատահական հարցով թեստ և Անիի էներգախնայողության արկածային խաղ
- `ecoenergy-avatar.png`՝ Telegram profile picture-ի համար
- API բանալիները պահվում են միայն `.env`-ում

## Գործարկում

1. BotFather-ում ստեղծիր բոտ և վերցրու token-ը։
2. `.env.example`-ը պատճենիր որպես `.env` և լրացրու `TELEGRAM_BOT_TOKEN`-ը։
3. ԱԲ-ի համար լրացրու `OPENAI_API_KEY`-ը։ Կարող ես օգտագործել OpenAI-compatible endpoint՝ `OPENAI_API_BASE`-ով։
4. Տեղադրիր կախվածությունները և գործարկիր.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Բոտը աշխատում է polling ռեժիմով, այնպես որ սկզբնական փորձարկման համար webhook կամ դոմեյն պետք չէ։ Production-ում խորհուրդ է տրվում աշխատեցնել systemd/Docker-ով և օգտագործել webhook։

## Հաջորդ բարելավումները

- SQLite/PostgreSQL՝ օգտատիրոջ արդյունքները պահպանելու համար
- Իրական սակագնի հաշվարկ՝ երկրի/մատակարարի սակագնով
- Admin panel և broadcast
- Ձայնային հարցեր ու PDF հաշվետվություն
